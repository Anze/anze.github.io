Highlights

Features a clean and intuitive interface that ensures a seamless user experience.

Access a complete month overview right from your device's home screen with handy widgets.

Kept Simple, On Purpose

A few things Good Old Calendar deliberately leaves out.

  • Marks days, not times - there's no time-of-day scheduling within a day
  • No text or notes per event; each marking type carries its own meaning globally, rather than per month or per event
